# Notice

This source release is a transparent paper-aligned implementation for peer review and
reproduction. It should not be described as a byte-identical copy of any unavailable historical
training repository. Implementation choices that were not uniquely determined by an early
manuscript version are stated explicitly in `PAPER_TO_CODE.md` and in the revised manuscript.

`results_reference/` contains manuscript/revision summary values only. Raw checkpoints,
per-epoch logs, datasets, and third-party model artifacts are not fabricated or bundled. If a
journal requests raw experimental evidence, the retained real artifacts should be deposited
separately.

The integration targets `ultralytics==8.3.59`. Ultralytics is distributed under AGPL-3.0;
this release is provided under AGPL-3.0-or-later as well.
